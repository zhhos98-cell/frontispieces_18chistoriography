# Gatterer 1762 frontispiece: evidence boundary — 26 August 2026

## Controlled facts

The National Library of Finland / Finna catalogue for Johann Christoph Gatterer's *Handbuch der neuesten Genealogie und Heraldik* (Nürnberg, 1762) explicitly records:

`Engr. front., signed 'M. Turoff fec. 1755'.`

The same record gives a concrete physical-copy collation and provenance, so this is a copy-specific bibliographic observation rather than a generic title-level inference.

Independent image controls establish the Type C seated-Historia/open-book composition in adjacent/nearby hosts:

- 1755: direct photographed physical copy, Type C;
- 1756: two independent photographed physical copies, Type C;
- 1757: direct photographed physical copy, Type C;
- 1761: direct photographed physical copy, Type C;
- 1763: BSB-derived public image, Type C.

## Current evidentiary status

Best current assignment:

`1762 = Type C probable, catalogue-signed M. Turoff fec. 1755`.

Do not promote to `verified_primary_image` until one image is directly paired with a 1762 title/copy identity or comes from the Finna copy itself.

The signature evidence is nevertheless already analytically strong enough to reject a simple Type-B-only interpretation of `fec. 1755`: Type C is directly present before and after 1755 and around 1762. If the 1762 image is confirmed as Type C, `fec. 1755` becomes a within-Type-C matrix/re-engraving/renewal question.
