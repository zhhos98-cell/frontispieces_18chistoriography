# Winkelmann sixth-part project identity: 1691 control and the 1697 + 184-page composite-copy anomaly

Date: 2026-08-28  
Status: HIGH-VALUE PROJECT/COPY-STATE CHECKPOINT — SIX-PART CHRONO-STEMMATO-POLEMOGRAPHIC PROJECT CONTROLLED BY 1691; STANDARD 1697 PRINT REMAINS FIVE PUBLISHED PARTS; A MARKET COPY WITH AN UNDATED 184-PAGE `SECHSTER THEIL` ATTACHMENT MUST NOT BE NORMALIZED AS A SIX-PART 1697 PUBLICATION

## Result

A new pre-publication control resolves an important part of the sixth-part problem while simultaneously exposing a copy-level cataloguing trap.

The Leibniz-Katalog record for **Ms 12, 713h Bl. 93** (ID **5924**, dated around April 1691) preserves a Leibniz note listing works Winkelmann still promised to publish. After `Hassiae chorographiam topographiam, Ethographiam, Hierographiam, politografiam`, the note records:

`Ejusdem chrono<stemmato-polemografiam principum> partibus sex`.

Source:

- Leibniz-Katalog, ID 5924, `Ms 12, 713h Bl. 93`, `für Landgraf Ernst (?)`: https://leibniz-katalog.bbaw.de/de/extended-search?id=5924&id_exact=true&view=list

This directly controls, **before the 1697 print**, both:

1. a six-part Hessian project architecture; and
2. a `chrono-stemmato-polemographia principum` component vocabulary closely corresponding to the later sixth-part identity.

The standard 1697 publication state nevertheless remains five published parts. The title itself says the work was composed in six parts but that only five were being published `vors erste`; HAB bibliography, Reiss copy collation, and later scholarly controls all treat Bremen 1697 as Parts I–V, with the sixth part appearing posthumously in Kassel in 1754.

A current Bassenge auction record is therefore anomalous when it describes a 1697 copy as:

`6 Teile in 1 Band. 10 Bl., 600 S., 184 S.`

and treats the 184-page tail as the sixth part under the label:

`Der Hessischen Chronic, in sich begreifende Chrono-stemmato-et polemographiam ducum, landgraviorum & principum Hassiae`.

A separate current antiquarian listing supplies a crucial control. It describes a 1697 copy with the normal collation:

`10 Bll., 600 Seiten`

and then separately lists among its `Beigebungen`:

`Winkelmann, Johann Just. Sechster Theil der Hessischen Chronik. Ohne Ort und Jahr. 184 Seiten (statt ?).`

Sources:

- Bassenge, auction 123, lot 216: https://bassenge.com/kataloge/123/WB?limit=15&page=15&view=list
- Antiquariat C. Dorothea Müller / ZVAB, seller inventory `9154AB`: https://www.zvab.com/erstausgabe/Gr%C3%BCndliche-Warhafte-Beschreibung-F%C3%BCrstenth%C3%BCmer-Hessen-Hersfeld/32405480619/bd

The safer current reconstruction is therefore:

`1691 six-part project identity`
≠ `1697 five-part publication state`
≠ `undated 184-page sixth-part attachment in a surviving/market copy`
≠ `1754 complete posthumous sixth-part publication`.

The 184-page object is real enough to require copy-level control, but its date, print state, completeness, and relationship to 1754 remain unresolved.

---

## 1. The six-part project predates the 1697 title page

The 1691 Leibniz note materially improves the title-form/version-history problem.

Before this control, the repository could say only that the 1697 title publicly presented a six-part project while printing five parts.

It can now say:

`SIX-PART PROJECT ARCHITECTURE BY c.1691 = CONTROLLED`.

Moreover, the note already associates that project with a sixth-component vocabulary centered on:

`chrono-` + `stemmato-` + `polemographia principum`.

This is not yet the full 1697 printed title phrase, and it does **not** establish that the formula:

`aus den glaubwürdigsten Documenten und Scribenten`

already existed in 1691.

The exact evidentiary-title formula remains a separate version-history question.

What is controlled is narrower and stronger:

> the six-part structure and chrono-stemmato-polemographic conception were not inventions of the 1697 title page or the 1754 posthumous editor.

---

## 2. Standard 1697 publication state remains five parts

Independent controls agree on the first edition:

- Bremen, Herman Brauer, 1697;
- approximately 10 preliminary leaves;
- 600 pages, with some catalogues noting the pagination as recte 598;
- Parts I–V published in one continuously paginated object;
- sixth part announced, not included as the normal publication state.

Strong controls:

- HAB bibliography: five parts with a sixth part only announced; true sixth appeared posthumously in 1754;
- Reiss & Sohn copy description: `5 Teile (von 6)`, `10 Bl., 600 S.`;
- Leibniz-Katalog bibliographical note: 1697 title says six composed / five published; 1711 contents still list five, followed by annotations/explanations; separate 1754 sixth part.

Sources:

- HAB WDB bibliography: https://diglib.hab.de/content.php?dir=edoc%2Fed000214&distype=optional&metsID=edoc_ed000214_einleitung_literatur_1&xml=einleitung%2Fliteratur.xml&xsl=tei-transcript_intro.xsl
- Reiss & Sohn auction catalogue 210, lot 1375: https://www.reiss-sohn.de/wp-content/uploads/auction-pdf/210.pdf
- Leibniz-Katalog, bibliographical control attached to ID 11623.

Therefore the following promotion is rejected:

`market copy contains an additional object called sixth part`
→ `1697 edition normally published six parts`.

## 3. Bassenge's 184-page tail is a copy/collation anomaly, not edition-level proof

Bassenge describes one object as:

`6 Teile in 1 Band. 10 Bl., 600 S., 184 S.`

with the entire object assigned to Bremen 1697.

That description conflicts with the stable edition-level bibliography.

The Müller/ZVAB record clarifies the structure by separating:

`1697 main work = 10 Bll. + 600 pp.`

from

`Beigabe = Sechster Theil der Hessischen Chronik, ohne Ort und Jahr, 184 pp. (statt ?)`.

The phrase `(statt ?)` itself signals incomplete or uncertain collation.

Current safest status:

`184-PAGE OBJECT = REPORTED COPY-LEVEL ATTACHMENT / FRAGMENT`

`DATE = UNRESOLVED`

`PLACE/PRINTER = UNRESOLVED`

`COMPLETE TEXT = NO / PROBABLY INCOMPLETE, BUT EXACT DEFECT UNRESOLVED`

`RELATION TO 1754 SIXTH PART = OPEN`.

Do not assign the 184 pages to Bremen 1697 merely because they are bound with or sold together with the 1697 five-part work.

## 4. Bassenge and Müller may describe the same physical copy, but identity is not yet verified

The two market records have conspicuously similar physical descriptions:

### Müller / ZVAB

- c. 34 × 20.5 cm;
- simple contemporary boards;
- binding rubbed/bumped;
- spine ends reinforced with paper;
- title damaged at margins and awkwardly reattached/reinforced;
- 1697 text plus undated 184-page sixth-part attachment.

### Bassenge

- c. 33 × 21 cm;
- contemporary boards;
- rubbed/bumped/stained;
- spine ends inexpertly reinforced;
- title inexpertly strengthened at inner margin, with marginal damage;
- 10 leaves + 600 pp. + 184 pp.

This is enough to generate a **probable same-copy hypothesis**, but not enough to verify copy identity without images, provenance, seller history, or stable defects.

Status:

`MÜLLER INVENTORY 9154AB ≈ BASSENGE LOT 216 = PROBABLE COPY-IDENTITY HYPOTHESIS`.

Do not promote to `same_copy_as` yet.

## 5. The genuine 1754 sixth part is materially different

The ULB Sachsen-Anhalt digital record for the posthumous sixth part gives:

- Kassel, Jeremias Estienne, 1754;
- `8 ungezählte Seiten, 490, 67 Seiten`;
- title explicitly beginning `Johann Just Winkelmanns Sechster Theil...`;
- subtitle identifying the work as the `Zeit- Stamm- Kriegs- und Regenten-Buch der Fürsten und Landgrafen zu Hessen`;
- documentary formula `Aus glaubwürdigen Documenten und Scribenten ordentlich verfasset`;
- a complete register over all six parts.

Source:

- ULB Sachsen-Anhalt / Share_it: https://opendata.uni-halle.de/handle/1981185920/75821 ; DOI `10.25673/73869`; VD18 `11053887`.

Thus:

`184-page undated attachment`
≠ `complete 1754 edition-level sixth part`.

The 184-page attachment could still be a **fragment of** the 1754 sixth part, an earlier/other print state, or another incomplete derivative witness. Direct comparison is required.

## 6. A conceptual continuity is now visible from 1691 to 1754

The 1691 Leibniz note calls the promised component:

`chrono-stemmato-polemographiam principum`.

The 1754 German title renders the completed sixth part as:

`Zeit- Stamm- Kriegs- und Regenten-Buch der Fürsten und Landgrafen zu Hessen`.

Without claiming a word-for-word translation history, the structural equivalence is striking:

`chrono` → `Zeit-`

`stemmato` → `Stamm-`

`polemo` → `Kriegs-`

`principum` → `Fürsten und Landgrafen` / `Regenten-`.

Safe proposition:

> The posthumous 1754 sixth part preserves the conceptual architecture of a component that was already named in closely corresponding Latin-Greek compound vocabulary in a 1691 working note.

Still open:

- whether the 1754 editor inherited Winkelmann's exact heading from a manuscript;
- whether the 184-page attachment preserves an intermediate state;
- whether the 1691 note summarizes Winkelmann's own title wording or Leibniz's compression of it.

## 7. Why the 184-page object is potentially very important

If the 184-page tail can be physically/textually identified, it could resolve one of several distinct scenarios:

### Scenario A — incomplete 1754 copy

The object may simply be a title-defective or truncated fragment of the 1754 sixth part.

Test:

- does its first surviving text match 1754 pp. 1ff.?
- do type, signatures, catchwords, page layout, ornaments, and paper agree with Estienne 1754?
- does it stop exactly at p.184, or are leaves/pages missing irregularly?

### Scenario B — earlier print/proof state

The object may preserve an otherwise poorly catalogued earlier printing or proof state of sixth-part material.

Required before promotion:

- typography demonstrably differs from 1754;
- watermarks/paper point earlier;
- textual readings differ systematically;
- signatures/layout establish an independent forme/imposition history;
- provenance predates 1754 or otherwise supports early circulation.

### Scenario C — later extract/recombination

The 184 pages may be an extracted or selectively bound portion of the 1754 text, later attached to a 1697 copy to create a materially 'completed' six-part set.

This would itself be valuable evidence for owner/dealer completion practices.

At present **no scenario is promoted**.

## 9. Repository-level guardrail

This case is a near-perfect textual analogue to the frontispiece method.

For plates:

`programme identity ≠ composition identity ≠ plate identity ≠ impression/copy identity`.

For the Winkelmann sixth part:

`project identity`
≠ `component/title identity`
≠ `publication-state identity`
≠ `later completion identity`
≠ `bound-copy contents`
≠ `dealer catalogue description`.

The Bassenge anomaly is therefore analytically productive: it shows how a real 1691 project identity can be retrospectively made to look like a 1697 publication fact when an undated fragment/attachment is collapsed into the host edition.

`PROJECT IDENTITY / COPY COMPLETION / CATALOGUE COLLAPSE`.
