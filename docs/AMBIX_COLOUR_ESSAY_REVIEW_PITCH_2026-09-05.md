## 3. Link to the frontispieces project

The relevance to this repository is not that the frontispiece project has become a general history of colour. The useful overlap is narrower.

One strand of the repository already follows colour and historiographical method in eighteenth-century Göttingen while tracing relevant printed practices backward into earlier Nuremberg book production. The controlled corpus includes historical tables, heraldic books, frontispieces, and several ways of representing colour in print. Existing colour notes also distinguish actual pigment from monochrome colour coding and from colour used as a relational or classificatory device.

If Ambix accepts the essay review, the external writing assignment could therefore serve as a bounded historiographical stress test for this branch of the project. It would require a firmer account of where recent book history and history of science have placed hand-colouring, colour printing, charts, samples, and paper tools. That work could strengthen the article-level historiographical framing without reopening generic source discovery.

This relation should remain asymmetric:

- the Ambix review would draw on the project's material-text interests;
- the frontispieces project should only absorb historiography that changes how its existing colour evidence is positioned;
- no new colour claim should be promoted merely because it is useful to the review essay.
