# Gabriel Müller–Martin Tyroff and the Type B frontispiece, 1723–1746 — 26 August 2026

## Status correction

Earlier work treated every frontispiece carrying `HISTORIA / GENEALOGIA / HERALDICA / TESTES TEMPORUM ET VERITATIS` as one target composition and therefore asked whether the Type A image visible in 1726 could already be Gabriel Müller’s design later engraved by Martin Tyroff. Direct image controls now rule out that framing.

The recurring inscription is a **programme**, not a unique composition. The directly controlled visual sequence includes:

- **Type A tree composition** by 1726 and still visible in 1738;
- **Type B architectural composition**, directly signed `G. Müller del.` / `M. Tyroff sc.` in 1744 and directly visible again in 1746;
- **Type C seated-Historia/open-book composition** by 1748.

This document therefore isolates the **production chronology of Type B**. It does not assign Müller or Tyroff to Type A merely because Type A carries the same verbal programme.

## I. Gabriel Müller is in Nürnberg from 1723

Lilian Ruhe’s 2019 biographical study gives the useful chronology:

- Gabriel Müller born Ansbach, 1688;
- ca. 1713–1722 court painter to Count Questenberg at Jaroměřice;
- **1723** followed Johann Kupezky from Vienna to **Nürnberg**;
- Nürnberg citizenship in 1734;
- marriage there in 1736.

The older 1733 date sometimes repeated for Müller’s move to Nürnberg should not be used.

This fact establishes only **chronological availability**. Müller could work in Nürnberg before the 1730s, but his presence in the city does not identify him as designer of Type A.

## II. Type A precedes the secure Müller–Tyroff Type B controls

A photographed 1726 Wappenkalender copy directly shows Type A. Institutional/market images then control Type A in 1728, 1733, 1737 and 1738.

The crucial correction is therefore:

> `programme present by 1726` does not mean `Müller–Tyroff Type B present by 1726`.

The designer and engraver of the early Type A composition remain unresolved unless a production signature can be read directly. Müller’s 1723 Nürnberg arrival keeps many production possibilities chronologically open, but no Type A attribution should be inferred from that biography.

## III. Tyroff’s firm role begins after the early Type A witnesses

British Museum authority material for Martin Tyroff records him as a Nürnberg engraver/publisher who married into Christoph Weigel’s family in **1729** and subsequently participated in running the inherited firm.

Two edges must remain separate:

1. **engraving/design work supplied to a publisher**;
2. **ownership/management integration into the Weigel family business**.

Even if future evidence assigns an early Type A matrix to Tyroff, that would not mean he already controlled the Weigel firm in 1726.

## IV. By 1733 Müller and Tyroff are directly documented as collaborators

A 1733 Altdorf dissertation, *Voluntarium Imperii consortium inter Fridericum Austriacum et Ludovicum Bavarum...*, presided over by Johann David Köhler, is catalogued by BSB / Deutsche Digitale Bibliothek with visual material including **two vignettes after Gabriel Müller engraved by Martin Tyroff**.

This gives a secure production relation:

`Köhler scholarly publication → Müller design → Tyroff engraving`.

Ruhe’s Müller study also lists Tyroff’s 1735 `Versöhnung der Gegenkaiser Friedrich von Österreich und Ludwig von Bayern` among prints after Müller. The Müller→Tyroff relationship therefore includes historical-political imagery rather than portrait production alone.

This collaboration is relevant context for Type B. It does not establish that every Weigel threshold image before or after 1733 was theirs.

## V. 1739 is now the first decisive Type B boundary candidate

A catalogue description of a 1739 Wappenkalender frontispiece reads the signatures:

- `G. Müller del`
- `M. Tyroff sc.`

Because Type A is directly visible in 1738 and Type B is directly signed with the same names in 1744, the 1739 witness is extremely high-information. Yet the signatures alone do not classify its composition: a direct image is still needed to establish whether the 1739 impression is Type B or another Müller/Tyroff design.

The secure statement is:

`1738 Type A direct image → 1739 Müller/Tyroff signed frontispiece, composition unresolved`.

If direct inspection shows 1739 Type B, the A→B replacement boundary collapses to **1738/1739**.

## VI. 1740 British Museum witness: strong Type B hypothesis, matrix question still open

British Museum object `1910,0906.2`, associated with the 1740 Weigel Wappenkalender, catalogues a frontispiece carrying the recurring programme as:

- print made by Martin Tyroff;
- after Gabriel Müller;
- published by the Heirs of Christoph Weigel;
- Nürnberg, 1740;
- approximately 198 × 115 mm.

Given the directly signed 1744 Type B witness, Type B is the strongest current composition hypothesis for the British Museum object. The attribution and shared programme do not substitute for image-level comparison.

Three distinct propositions must therefore stay separate:

1. 1740 is a Müller→Tyroff programme witness: **established by institutional catalogue**;
2. 1740 is Type B: **strong hypothesis pending direct composition comparison**;
3. 1740 and 1744 were printed from the same copper matrix: **unresolved**.

## VII. 1744: first direct signed Type B control

The ULB Düsseldorf 1744 digitisation directly shows the Type B architectural/interior composition and visibly reads:

- `G. Müller del.`
- `M. Tyroff sc.`

This is the current anchor for the Type B production family because both design and production names are controlled on the image itself.

The composition is graphically distinct from Type A. It should therefore never be described as merely a later state of the 1726/1728/1733/1738 tree composition without line-level evidence of some much stronger relationship than is currently visible.

## VIII. 1746: Type B persists

An archived Ricardo seller photograph of a physical 1746 Wappenkalender directly pairs a title page visibly dated 1746 with the Type B architectural frontispiece.

This extends direct Type B persistence from 1744 to 1746. Since ULB Düsseldorf directly shows Type C in 1748, the secure replacement sequence is now:

`1744 Type B → 1746 Type B → 1748 Type C`.

Thus **1747 alone** decides the current B→C boundary.

Same-matrix identity between 1744 and 1746 remains unproved until signatures, dimensions, frame, lettering and micro-defects are compared.

## IX. Production chronology now supported

The safe production/context sequence is:

`1723 Müller arrives Nürnberg`
→ `1726–1738 Type A programme witnesses; designers/matrices unresolved`
→ `1729 Tyroff marries into / becomes connected to management of Weigel family firm`
→ `1733 Müller→Tyroff collaboration documented in a Köhler scholarly publication`
→ `1739 Müller/Tyroff-signed programme frontispiece; composition unresolved`
→ `1740 British Museum Müller→Tyroff programme witness; Type B probable`
→ `1744 direct signed Type B`
→ `1746 direct Type B`
→ `1748 direct Type C`.

This chronology supports a more precise article-level distinction among:

- programme adoption;
- composition replacement;
- artist/engraver collaboration;
- firm incorporation;
- matrix custody and reuse.

Those events need not coincide.

## X. Current hypotheses

### H1 — Type B enters in 1739

If the 1739 image is Type B, the clean boundary is:

`1738 Type A → 1739 Type B`.

The 1740/1744/1746 witnesses would then form a candidate Type B persistence sequence. Same matrix still requires state comparison.

### H2 — Müller/Tyroff signed another composition in 1739

If 1739 is not Type B, the Müller/Tyroff collaboration and Type B introduction must be separated. Direct 1740 comparison then becomes the next boundary test.

### H3 — multiple Type B matrices/states

Even if 1739, 1740, 1744 and 1746 all prove Type B, one graphic design may have been cut or renewed on more than one copper. Dimensions, signature wording, frame geometry, stable scratches/defects, retouching and wear are required before `same_plate_as`.

## XI. What is now ruled out

Do not argue:

> the 1726 frontispiece is the same target composition later catalogued by the British Museum as Müller after Tyroff.

The 1726 witness is Type A; the secure Müller–Tyroff composition in 1744/1746 is Type B.

Do not argue:

> Müller’s 1723 presence in Nürnberg proves he designed Type A.

It establishes chronological possibility only.

Do not argue:

> Tyroff’s later Weigel-firm role existed already in 1726.

His later business integration and any earlier engraving work are separate relationships.

## XII. Highest-information image tests

1. **1739:** obtain the opening frontispiece image and classify it A/B/C/new type; preserve the literal Müller/Tyroff signatures.
2. **1740 BM:** compare composition directly with 1744 Type B and record frame, lettering, signatures and defects.
3. **1744 ↔ 1746:** compare exact matrix/state features.
4. **1747:** classify frontispiece to locate the Type B→Type C replacement to 1747 or 1748.
