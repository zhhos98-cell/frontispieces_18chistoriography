# Winkelmann's Hessian Chronicle: pagination, source-state inheritance, and the missing `Geographica` excerpt, c.1655–1697

Date: 2026-08-28  
Status: HIGH-VALUE SOURCE-STATE / MATERIAL CONTROL — 1690 GEOGRAPHICA-DESTINATION EXCERPT REPORTED NOT FOUND BY CRITICAL-EDITION EDITORS; LEIBNIZ AUTOGRAPH PAGINATION DIRECTLY CONTROLLED IN A 1694? WORKING NOTE; LATER 1697 PRINT PROVIDES PARTIAL PAGE-LEVEL TEXTUAL MATCHES; OLDENBURG CIM I 204 CONTROLS A LARGE CONTEMPORANEOUSLY PAGINATED WINKELMANN MANUSCRIPT TRADITION BUT IS NOT IDENTIFIED AS LEIBNIZ'S EXACT SOURCE

## Result

The current pagination problem can now be resolved at a finer evidentiary level.

Three things must be kept separate:

1. **modern catalogue source alignment** — the Leibniz-Katalog can identify a Leibniz note against a later printed work and supply a printed page locator;
2. **Leibniz's own source pagination** — at least one relevant autograph note itself contains repeated page references to `W. Hassicae Chron.`;
3. **physical identity of the 1690 `Geographica` excerpt reservoir** — the critical edition explicitly reports that the excerpt referenced by Leibniz's 1690 `Insignia` cross-reference could not be found.

The safest current model is therefore:

`Winkelmann paginated manuscript / written-work tradition`
→ `partial excerpt access / Geographica-side source reservoir by 1690`
→ `1690 problem-note cross-reference to a now-unrecovered excerpt`
→ `1694? Leibniz collectanea using stable page locators in a Hessian-Chronicle source state`
→ `1697 printed German Beschreibung with partial page-level continuity / textual correspondence`.

This does **not** yet establish that the 1690 missing `Geographica` packet and the 1694? paginated source state were physically identical.

Working label:

`PAGINATED PREPRINT SOURCE TRADITION + PARTIAL PAGINATION CONTINUITY; EXACT SOURCE-WITNESS IDENTITY UNRESOLVED`.

## 1. Critical-edition control: the 1690 referenced `Geographica` excerpt was not found

The official critical edition of Hannover NLB `Ms XXIII 47(1)` prints Leibniz's June 1690 record N.20, corresponding to Leibniz-Katalog ID **7139**, `Bl.21`.

The record is a short `Insignia` note concerning the two lions of the Counts of Diez. Leibniz points away from the note itself to Winkelmann/Hessian-Chronicle excerpts kept with `Geographica`.

Most importantly, the editors state that the excerpt to which Leibniz refers **could not be located** and infer only that a writing by Johann Just Winkelmann probably underlay it.

Official critical-edition PDF:

https://leibnizp1.bbaw.de/fileadmin/Webdateien/Dateien/Ms_23_47.pdf

N.20, p.13 of the current working edition.

Evidence status:

`CRITICAL-EDITION EDITORIAL NON-RECOVERY CONTROL + PRIMARY AUTOGRAPH CROSS-REFERENCE`.

### Consequence

The previous repository wording:

`physical Geographica packet not yet reconstructed`

must now be strengthened and narrowed:

> **For the specific excerpt referenced by the June 1690 ID 7139 / N.20 cross-reference, the current critical-edition editors themselves report that it has not been found.**

This is not proof that every Winkelmann/Hessian item once kept under `Geographica` is lost. It is a witness-specific non-recovery statement.

Therefore do not treat ID **69098** or later 1694 notes as the recovered physical object of N.20 merely because they also mention Winkelmann and `Geographica`.

## 2. Modern catalogue page locators are not automatically contemporary source pagination

The Leibniz-Katalog field `Exzerpierte Stelle` identifies the work and locus from which Leibniz excerpted or paraphrased material. In some records the modern catalogue can align a note to a source printed **after the assigned date of the Leibniz working paper**.

A relevant example is ID **12220**, `LH 12,1,3 Bl.123`, assigned with uncertainty to the 1694 historical-working complex and filed `Saxones sub Romanis`. The catalogue identifies the corresponding passage in Winkelmann's **1697** printed *Beschreibung* at p.400.

That printed page locator is therefore an editorial/source-identification datum. By itself it cannot prove that Leibniz's pre-1697 source already carried page 400.

Repository rule:

> `catalogue Exzerpierte-Stelle page` ≠ automatically `page number visible to Leibniz at time of note`.

This distinction must be applied record by record.

Official catalogue query:

https://leibniz-katalog.bbaw.de/de/extended-search?ordnungsvermerk_normiert=Sub+Romanis&view=list

## 3. ID 11623 reverses the simple editorial-pagination explanation

Leibniz-Katalog ID **11623** is different.

Shelfmark:

`LH 12,1,3 Bl.112`.

Title:

`Collectanea de "Saxoniae habitatoribus sub Romanos". Exzerpte u. Notizen`.

Date:

`1694` with catalogue uncertainty (`ca.?`).

Text type:

Leibniz autograph note.

Format:

`Quart, 1 Seite/Spalte`.

Ordering mark:

`Nostra sub Romanis`.

Its **autograph wording itself** begins by citing `W. Hassicae Chron.` with page 6 and later invokes further page locators including **41, 56, 59 and 96**.

Official catalogue:

https://leibniz-katalog.bbaw.de/de/extended-search?ordnungsvermerk_normiert=Sub+Romanis&view=list

Evidence status:

`PRIMARY AUTOGRAPH PAGINATION CONTROLLED THROUGH OFFICIAL CATALOGUE TRANSCRIPTION`.

### Consequence

There was a Winkelmann/Hessian-Chronicle source state accessible to Leibniz in which **stable page-number retrieval was possible**.

The page numbers cannot all be dismissed as modern editorial additions.

At the same time, ID 11623 is a Leibniz **collectanea sheet**, not the missing `Geographica` source packet itself.

Therefore its page references could point to:

1. a full paginated manuscript;
2. a paginated pre-print / printer's manuscript;
3. a paginated copy or derivative source;
4. an excerpt packet that retained the pagination of its parent source.

Current evidence does not discriminate among these possibilities.

## 4. Partial page-level continuity into the 1697 print

The long catalogue note for ID 11623 compares Leibniz's working note with Winkelmann's 1697 printed *Gründliche und Warhafte Beschreibung der Fürstenthümer Hessen und Hersfeld* and identifies matching/helpful passages across printed pages including 40–41, 54–56, 59, 69 and 96.

Several printed loci therefore coincide exactly or nearly with page references written by Leibniz in the pre-1697 working note, especially **41, 56, 59 and 96**.

This supports:

`PARTIAL PAGINATION / LOCUS CONTINUITY`.

It does **not** support:

`complete pagination identity between Leibniz's source and the 1697 print`.

The opening autograph reference to p.6 is an important warning: the catalogue's later-print comparison does not simply map every autograph page number one-to-one.

Thus the strongest safe proposition is:

> **At least part of the page architecture of the pre-print Hessian-Chronicle source state used by Leibniz appears to survive into the 1697 printed text, but the relationship is not yet proven to be globally identical.**

## 5. Oldenburg `Cim I 204`: a large contemporaneously paginated Winkelmann manuscript tradition

A major external manuscript control has now been recovered in the Herzog August Bibliothek manuscript database for Landesbibliothek Oldenburg:

`Cim I 204`

`Iohannis Justi Wynkelmanni Hassiacarum rerum libri`.

Catalogue description:

- paper manuscript;
- 553 leaves;
- approximately 33 × 21.5 cm;
- Darmstadt / Oldenburg provenance context;
- dated broadly between 1647 and 1699;
- **contemporary pagination** in several sequences;
- numerous inserted and pasted materials;
- two separate states of book IV, each carrying different authorial corrections/additions;
- extracts from princely letters concerning the Hessian Chronicle at the end.

The manuscript catalogue further records an earlier attached item concerning the long course and delayed publication of the Hessian Chronicle, transferred to the Hessisches Staatsarchiv Darmstadt in 1941 and reported missing there after the war.

HAB manuscript record:

https://diglib.hab.de/?catalog=Bley&db=mss&hi=Thomas&id=ol-lbo-cim-i-204&list=ms

Evidence status:

`INSTITUTIONAL MANUSCRIPT-CATALOGUE / MATERIAL-WITNESS CONTROL`.

### What this proves

Winkelmann's Hessian historical project existed as a **large, paginated, revisable manuscript apparatus** long before the 1697 German print.

The source ecology included:

`continuous / repeated pagination`
+
`insertions`
+
`pasted additions`
+
`authorial corrections`
+
`variant book states`
+
`administrative correspondence about the Chronicle`.

This makes a paginated pre-print source available to excerptors historically ordinary rather than exceptional.

### What this does not prove

`Cim I 204` is a Latin Hessian-Chronicle manuscript tradition, and the catalogue explicitly notes that its exact relation to the later German version remains historically complex. A later owner described the printed German work as substantially different from the Latin manuscript.

Therefore:

`Oldenburg Cim I 204 = Leibniz's exact W. Hassicae Chron. source`

is **not established**.

Use it as a material comparator and proof of the wider manuscript ecology, not as witness identity.

- tiny `Insignia` note;
- points to Hessian-Chronicle excerpts under `Geographica`;
- referenced excerpt reported not found by the editors.

### 1694?

ID **11623**:

- separate Quart autograph collectanea;
- `Nostra sub Romanis`;
- direct page citations into a Hessian-Chronicle source state.

### 1694

ID **14091**:

- `Antiquissimi habitatores` strip;
- independently points to Winkelmann/Hessian excerpts kept with `Geographica`.

These records support persistence of a retrieval relation across several years, but not one unchanged physical packet.

Possible histories include:

1. the 1690 packet survived and was still consulted in 1694 but later disappeared;
2. the 1690 packet was replaced or augmented by further Winkelmann extracts;
3. Leibniz encountered a fuller paginated source in the intervening years;
4. several source reservoirs coexisted under the broad practical destination `Geographica`.

Current label:

`PERSISTENT GEOGRAPHICA RETRIEVAL RELATION; PHYSICAL CONTINUITY UNPROVED`.

## 7. Refined source-state sequence

Combining this checkpoint with the preceding 1690–1701 source-state reconstruction gives:

### A. Authorial manuscript ecology

By the mid-seventeenth century and later, Winkelmann's Hessian-history project exists in extensive written, corrected and paginated manuscript states.

### B. Partial access

By June 1690 Leibniz has access to Hessian-Chronicle excerpts and sends an `Insignia` inquiry to a `Geographica` retrieval location.

### C. Whole-work distinction

Around 1691 Leibniz still distinguishes those partial materials from the written Hessian Chronicle itself and expresses interest in reading the whole written work while printing remains delayed.

### D. Stable pagination

A 1694? Leibniz autograph collectanea uses repeated page locators into a Hessian-Chronicle source state.

### E. Printed state

The 1697 printed German work retains textual and at least partial page-level correspondences with those earlier notes.

### F. Later printed-state recognition

By 1701 Leibniz explicitly distinguishes the printed tome he has seen from the larger work's publication history.

This is best understood as **versioned access**, not one source moving unchanged from manuscript to print.

The Winkelmann case now supplies an unusually clean analogue to the frontispiece project's own witness discipline.

For source texts:

`work identity`
≠ `manuscript state`
≠ `excerpt packet`
≠ `problem-note citation`

This directly parallels the visual rule:

## 9. Consequence for `Geographica` as a research space

The critical-edition non-recovery of the 1690 excerpt changes the conceptual status of `Geographica`.

The category is visible to us partly through **pointers to absent material**.

This means its archival architecture cannot be reconstructed only by counting surviving items explicitly carrying `Geographica` ordering marks.

A more adequate model must include:

- surviving destination files;
- surviving cross-references;
- missing referenced packets;
- later or differently filed derivative notes;
- source states reconstructed from print/manuscript comparison.

Thus `Geographica` was not necessarily a closed folder whose full contents survive. It functioned as a **retrieval jurisdiction whose historical extent exceeds the surviving normalized catalogue hit set**.

This is important for any quantitative use of the 53 current `Geographica` catalogue results.

## 10. Consequence for the frontispiece argument

The frontispiece visually presents stable, differentiated domains and witnesses.

The Winkelmann reconstruction shows the prior evidentiary economy to be materially much less stable:

`whole manuscript tradition`
→ `partial excerpt reservoir`
→ `cross-file pointer`
→ `missing source packet`
→ `autograph collectanea with source page locators`
→ `later print`
→ `modern editorial re-identification`.

Historical knowledge can therefore become visually and taxonomically coherent even when its documentary carriers are **distributed, versioned, partially missing and retrospectively re-aligned**.

This strengthens the larger repository proposition:

> **The constitution of historical knowledge was an operation of coordination across non-identical and mobile witnesses, not merely the representation of already stable auxiliary sciences.**
