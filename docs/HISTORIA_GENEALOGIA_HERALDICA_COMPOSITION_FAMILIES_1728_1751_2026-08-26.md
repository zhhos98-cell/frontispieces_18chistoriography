# Historia–Genealogia–Heraldica frontispiece composition families, 1728–1751 — 26 August 2026

## Research correction

Direct inspection of the ULB Düsseldorf digitised annuals changes the identification problem materially. The inscription

`HISTORIA. GENEALOGIA. HERALDICA.`

`Testes temporum et veritatis.`

is **not a unique identifier for one engraved composition or one copperplate**. Within the same calendar series, the stable verbal programme survives across at least three visibly different frontispiece designs.

The correct hierarchy is therefore:

`inscription/programme identity ≠ composition/design identity ≠ matrix/plate identity ≠ impression identity`.

Earlier records that used “Clio” or the Latin inscription as shorthand for a single target plate must be read provisionally until the image is assigned to a composition family.

## Composition taxonomy

### Type A — tree composition

Directly verified in 1728, 1733 and 1738. The composition places Historia, Time, heraldic/genealogical media and putti in an outdoor/tree-dominated arrangement. This design predates the directly verified Müller–Tyroff architectural image below.

At present, these three impressions establish **design persistence**, not necessarily one uninterrupted physical copper matrix. Plate identity still requires signature, dimension, defect, wear and line-state comparison.

### Type B — Müller–Tyroff architectural composition

Directly verified in the 1744 Düsseldorf copy and signed `G. Müller del.` / `M. Tyroff sc.`. This is the strongest image-level control for the design independently attributed by the British Museum in its 1740 frontispiece record to Martin Tyroff after Gabriel Müller.

The 1739 catalogue reading `G. Müller del / M. Tyroff sc.` and the British Museum 1740 attribution are therefore best treated as controls for a **Müller–Tyroff design family**. Same-matrix identity between 1739, 1740 and 1744 still requires image/plate-state comparison.

### Type C — seated Historia / open-book composition

Directly verified in 1748 and 1751. This is not the Type A tree design and not the Type B architectural standing-Historia design. The 1751 image appears to carry `M. Tyroff fec.` at lower right, making Tyroff’s role in serial redesign/re-engraving an immediate plate-history question.

Again, 1748 and 1751 are assigned to the same **composition family** only. Same copperplate is not yet asserted.

## Consequences for the existing chronology

The old question “when does the Historia/Genealogia/Heraldica frontispiece appear?” now separates into at least three questions:

1. When does the **verbal programme / motto** first appear?
2. When does each **composition family** enter and leave the series?
3. Within each composition family, how many **physical matrices / plate states** were used?

This materially changes the interpretation of the serial apparatus. The strongest current pattern is not uninterrupted survival of one picture. It is **programmatic continuity under graphic replacement**: the same threshold wording and evidentiary allegory are retained while the visual organisation of Historia, genealogy, heraldry, Time, books, tables and other witnesses is redesigned.

That pattern fits the project’s provenance-first rule especially well. A title-like inscription can persist at the level of serial identity while image design and copper matrix change underneath it.

## Immediate reclassification of later controls

The 1755, 1759 and 1762 witnesses should no longer be tested first against a generic “Clio” identity. The correct order is:

1. classify the image as Type A, Type B, Type C, or a new Type D;
2. transcribe production signatures diplomatically;
3. compare dimensions, frame, lettering, small line defects and wear only within the same composition family;
4. only then make a same-matrix or re-engraving claim.

This is especially important for the 1762 catalogue signature `M. Turoff fec. 1755`. A date/signature by itself cannot prove that the 1762 plate is a second state of the earlier Müller–Tyroff Type B design; it may belong to Type C or another composition.

## Provenance/circulation side-control: Gandersheim

The reconstructed 1760 catalogue of the Reichsstift Gandersheim library contains an entry transcribed as:

`Historia Genealogia Heraldica de An. 1751 et 1752. S. 26, N. 6`

The modern reconstruction marks the item as not identified. This is not yet a plate witness. It is nevertheless significant because the frontispiece phrase appears to function as a **cataloguing handle for annual material**, possibly a bound or paired 1751/1752 unit. It should be treated as evidence for reception/circulation of the serial verbal programme until the historical volume is identified.

Reconstruction: HAB / Bibliothek des Reichsstiftes Gandersheim, based on the old catalogue now in Staatsarchiv Coburg, LAA 5772.
