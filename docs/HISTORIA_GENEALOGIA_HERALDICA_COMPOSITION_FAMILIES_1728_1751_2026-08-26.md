# Historia–Genealogia–Heraldica frontispiece composition families, expanded 1726–1763 — 26 August 2026

## Research correction

Direct image controls now show that the inscription

`HISTORIA. GENEALOGIA. HERALDICA.`

`Testes temporum et veritatis.`

is **not a unique identifier for one engraved composition or one copperplate**. Within the same serial ecology, the stable verbal programme survives across at least three visibly different frontispiece designs.

The correct hierarchy is therefore:

`inscription/programme identity ≠ composition/design identity ≠ matrix/plate identity ≠ impression identity`.

Earlier records that used “Clio” or the Latin inscription as shorthand for a single target plate must be read provisionally until the image is assigned to a composition family.

## Composition taxonomy

### Type A — tree composition

Directly verified in **1726, 1728, 1733, 1737 and 1738**. The composition places Historia, Time, heraldic/genealogical media and putti in an outdoor/tree-dominated arrangement.

This is now a real persistence interval rather than a cluster of isolated identifications: the target verbal programme is visibly present in the series by 1726 and Type A remains demonstrably in use through 1738. Plate identity across those impressions still requires signature, dimension, defect, wear and line-state comparison.

The 1724 negative remains important: a surviving copy is described with a different annual-memory frontispiece. The highest-information early transition is therefore now **1725 versus 1726** at the level of verbal programme/design adoption.

### Type B — Müller–Tyroff architectural composition

Directly verified in the 1744 Düsseldorf copy and signed `G. Müller del.` / `M. Tyroff sc.`. This is the strongest image-level control for the design independently attributed by the British Museum in its 1740 frontispiece record to Martin Tyroff after Gabriel Müller.

A crucial caution follows from the Type A discoveries. The 1739 catalogue reading `G. Müller del / M. Tyroff sc.` does **not by itself** prove that the 1739 image is Type B, because the artists responsible for Type A have not yet been diplomatically resolved. The 1740 British Museum image/design should therefore be inspected directly before using 1739/1740 as the left boundary of Type B.

The secure graphic replacement window is currently:

`Type A directly visible in 1738 → Type B directly visible in 1744`.

### Type C — seated Historia / open-book composition

Directly verified in **1748, 1751, 1761 and 1763**. This is not Type A and not the 1744 Type B design. The stable visual programme has been reorganised around a seated winged Historia and large open book.

The interval is now especially consequential because a 1762 Gatterer copy is catalogued with a frontispiece signed `M. Turoff fec. 1755`. Since Type C already exists by 1751, a literal `fec. 1755` on a Type C 1762 impression could not simply mark the first invention of the Type C composition. It would instead raise a narrower plate-history problem: **re-engraving, replacement matrix, retouch/state, or catalogue/signature-reading issue**.

The direct 1761 and 1763 Type C controls also make it substantially more likely that the intervening 1762 frontispiece belongs to Type C, but yearly alternation remains logically possible. Direct inspection of 1762 is still decisive.

The secure Type B → Type C replacement window is currently:

`Type B directly visible in 1744 → Type C directly visible in 1748`.

## Consequences for the existing chronology

The old question “when does the Historia/Genealogia/Heraldica frontispiece appear?” now separates into at least four questions:

1. When does the **verbal programme / motto** first appear?
2. When does each **composition family** enter and leave the series?
3. Within each composition family, how many **physical matrices / plate states** were used?
4. How does a composition persist or get replaced when the host changes from annual calendar to Gatterer handbook?

The strongest current pattern is **programmatic continuity under graphic replacement**. The same threshold wording survives while the visual organisation of Historia, genealogy, heraldry, Time, books, tables and other witnesses is repeatedly redesigned.

The later evidence strengthens that interpretation further: Type C crosses the bibliographic regime change from Weigel calendar to Gatterer *Handbuch*. Thus the unit of continuity is not simply the annual title or one copperplate. It is a reusable threshold programme whose graphic carrier can outlive, cross, or be remade across host formats.

## Reclassification of later controls

The 1755, 1759 and 1762 witnesses should be tested in this order:

1. classify the image as Type A, Type B, Type C, or a new Type D;
2. transcribe production signatures diplomatically;
3. compare dimensions, frame, lettering, small line defects and wear only within the same composition family;
4. only then make a same-matrix, re-engraving or plate-state claim.

The 1761/1763 Type C controls make the 1762 image particularly high-value. If it is Type C and really reads `M. Turoff fec. 1755`, then the problem becomes a **within-Type-C matrix history**, not a Type B continuity question.

## Provenance/circulation side-control: Gandersheim

The reconstructed 1760 catalogue of the Reichsstift Gandersheim library contains an entry transcribed as:

`Historia Genealogia Heraldica de An. 1751 et 1752. S. 26, N. 6`

The modern reconstruction marks the item as not identified. This is not yet a plate witness. It is nevertheless significant because the frontispiece phrase appears to function as a **cataloguing handle for annual material**, possibly a bound or paired 1751/1752 unit. The direct 1751 Type C control now makes the unidentified 1752 companion especially useful for testing Type C persistence and historical reception.

## Current discriminating checks

- **1725**: inspect title copper; if it carries the programme, classify composition and establish whether adoption begins in 1725 or 1726.
- **1739/1740**: inspect image(s) directly to locate the Type A → Type B replacement more tightly; do not infer Type B from signature alone.
- **1745–1747**: any image-level witness can narrow the Type B → Type C replacement window.
- **1752**: classify the frontispiece to test the Gandersheim 1751/1752 pairing and Type C persistence.
- **1755**: reclassify the photographed frontispiece by composition and enlarge the signature.
- **1759**: classify the first Gatterer-handbook frontispiece; this is the key host-regime crossover.
- **1762**: inspect directly and resolve whether `M. Turoff fec. 1755` belongs to Type C; compare within Type C rather than against generic “Clio”.

## Evidentiary guardrail

Use the Latin motto as a **serial/programmatic identifier**, never by itself as a same-image or same-plate identifier. Use “Type A/B/C” only for composition-level grouping until plate-state evidence justifies stronger language.
