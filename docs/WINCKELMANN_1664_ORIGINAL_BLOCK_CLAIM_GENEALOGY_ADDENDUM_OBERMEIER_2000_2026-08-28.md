# Addendum: Obermeier 2000 already narrows Winckelmann to some original Staden matrices

Date: 2026-08-28  
Status: DIRECT SCHOLARLY-TEXT CONTROL — THE `SOME ORIGINAL MATRICES + ARBITRARY RELOCATION` MODEL IS DOCUMENTED BY 2000, NOT ONLY IN OBERMEIER 2014.

## Result

Franz Obermeier's monograph *Brasilien in Illustrationen des 16. Jahrhunderts* (Frankfurt am Main: Vervuert, 2000) supplies an earlier direct control for the repository's current Winckelmann/Staden matrix model.

In a note discussing Staden's visual tradition, Obermeier writes:

`Winckelmann standen auch die Platten einiger Holzschnitte der editio princeps Stadens zur Verfügung, die er in seinem Text an beliebigen Stellen eingefügt hat.`

The important propositions are separate and explicit:

1. `Platten einiger Holzschnitte` — only **some** of the princeps woodcut matrices/blocks were physically available to Winckelmann;
2. `an beliebigen Stellen eingefügt` — those inherited images were inserted at arbitrary locations in the 1664 text.

Thus by 2000 the scholarly model is already:

`SOME ORIGINAL 1557 PHYSICAL MATRICES AVAILABLE`
+
`ARBITRARY 1664 REDEPLOYMENT`

rather than:

`ALL 32 STADEN-SECTION IMAGES = VERIFIED ORIGINAL MATRICES WITH PRESERVED TEXT-IMAGE RELATION`.

This predates Obermeier's 2014 formulation:

`wohl nur ein Teil der originalen Druckstöcke erhalten, keine korrekte inhaltliche Zuordnung, illustrativ eingesetzt`.

The 2014 statement is therefore best understood as a later, more explicit restatement of an analytical distinction already present in Obermeier's 2000 work.

## Relation to Fouquet 1964

The same note refers to `Staden 1964, Abb. 55` for the apocryphal Staden portrait immediately before the sentence about the surviving matrices. That makes the Maack/Fouquet 1964 edition an important upstream control, but the current searchable note does **not** establish that Fouquet is the source of the exact `einiger Holzschnitte` proposition.

Therefore:

`FOUQUET 1964 AS UPSTREAM SOURCE FOR SOME-BLOCK LIMIT = POSSIBLE / UNVERIFIED`.

The repository should still recover Fouquet's own p.32 before assigning this proposition to him.

## Genealogical consequence

The assertion-history is now better represented as two competing or partially overlapping twentieth-century traditions rather than a simple modern JCB-vs-2014 split:

`1664 Winckelmann: ~34 recovered blocks + Staden attribution ('sonder Zweifel')`
→ `1870 Quaritch: neutral visual description`
→ `1925 Wegner: exact p.19 still unresolved`
→ `1930s bibliographic hardening: 'original woodcuts' / 'same blocks'`
→ `1964 Fouquet: exact p.32 still unresolved`
→ `2000 Obermeier: some princeps matrices + arbitrary placement`
→ `2014 Obermeier: probably only part of original block stock preserved + incorrect content assignment`
→ `modern JCB/Open Library: numericalized 32-fold original-block claim`.

The chronological point is important: the narrower matrix model does not look like a late reaction invented after modern JCB metadata. It is already explicit in a substantial scholarly monograph in 2000.
