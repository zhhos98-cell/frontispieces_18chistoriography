# Winkelmann Hessian Chronicle pagination before the 1697 print: source-state control, 1690–1697

Date: 2026-08-28
Status: HIGH-VALUE MATERIAL-SOURCE-STATE CONTROL — LEIBNIZ'S OWN PAGINATION REFERENCES ARE DIRECTLY CONTROLLED; EXACT PHYSICAL FORM OF THE PRE-PRINT SOURCE REMAINS OPEN

## Result

The page references attached to Leibniz's early Winkelmann/Hessian Chronicle notes are not a modern editorial back-reference to the 1697 printed book.

Leibniz's autograph note now catalogued as LH 12, 1, 3 Bl. 112, dated by the Leibniz-Katalog to 1694 and printed in Akademieausgabe V as 3100.097, begins explicitly:

`Ex W. Hassicae Chron. p. 6.`

The same note later contains further source locators including `p. 56`, `p. 59`, and `p. 96`.

The catalogue separately supplies a modern identification of the source environment as Johann Just Winkelmann, *Gründliche und Wahrhafte Beschreibung der Fürstentümer Hessen und Hersfeld* (Bremen, 1697), with additional comments comparing the later print tradition. The pagination markers, however, belong to Leibniz's own note text.

Therefore:

`Leibniz pagination reference`
≠
`modern editor-added 1697 print locator`.

The strongest present inference is that Leibniz worked from a pre-1697 textual state carrying stable page numbers or page-like locators.

Current admissible physical models are:

1. a paginated manuscript/pre-publication copy;
2. a paginated excerpt-copy derived from Winkelmann's working manuscript;
3. an early proof / printer's copy carrying pagination later preserved or partly preserved in print.

The evidence does not yet distinguish these three.

Do **not** state that Leibniz read the 1697 printed edition in 1694.

- Winkelmann, *Gründliche und Wahrhafte Beschreibung der Fürstentümer Hessen ...*, Bremen 1697;
- Bremen 1711 reissue/reprint history;
- posthumous sixth part, Kassel 1754;
- later printed pages whose contents correspond to or help control Leibniz's notes.

This field separation is methodologically important.

It means that the editors did not simply insert the later print pagination into Leibniz's transcription. The note itself already carried source pagination.

Working evidence distinction:

`AUTOGRAPH LOCATOR`
versus
`EDITORIAL SOURCE IDENTIFICATION / LATER PRINT COLLATION`.

## 3. Earlier source-state evidence already proves a written Hessian Chronicle before print

A separate checkpoint has established the pre-print history independently.

Around April 1691 Leibniz records a wish to be allowed to read the:

`geschriebene heßische Chronick selbst`

especially if printing would still be delayed for a long time.

In the immediately associated Winkelmann material, Winkelmann refers to:

`meiner lezten und teutschen heßischen Chronik`

and says that the histories of twenty-eight extinct Hessian lordships had been inserted into it.

Thus a substantial written Hessian Chronicle existed before the Bremen 1697 edition.

This makes a pre-print pagination system historically plausible independently of the 1694 note.

---

## 4. Excerpt reservoir precedes access to the whole written Chronicle

The archive evidence now supports a layered source-access model.

Leibniz could already refer to:

`Excerpta ex Winkelm. Hass. so liegen bey Geogr.`

while still wishing to see the `geschriebene heßische Chronick selbst`.

This implies:

`whole written work`
≠
`excerpt reservoir available to Leibniz`.

The excerpt reservoir could preserve pagination copied from its source without requiring Leibniz to possess the entire manuscript.

This is currently the most economical explanation for the coexistence of:

- stable page references;
- distributed excerpts;
- cross-file pointers to `Geographica`;
- later desire to inspect the complete written Chronicle.

## 5. Cross-jurisdiction use remains visible

The Hessian source reservoir was not confined to one thematic file.

Controlled references include:

- `Nostra / Saxones sub Romanis` — early peoples under Roman rule;
- `Antiquissimi habitatores` — standing stones at Miltenberg and Zwingenberg, explicitly pointing to the Winkelmann Hessian excerpts stored under Geography;
- `Linguae | Geographica` — linguistic/ethnonymic note `Hess ... Heßen Catti vid. excerpt. ex Winkelm.`;
- `Insignia` — separate Winkelmann-derived dynastic/heraldic materials already reconstructed elsewhere.

The relevant archival architecture remains:

`source reservoir`
→ `problem-specific extraction`
→ `routing to Geographica / Genealogica / Insignia / other files`
→ `reuse in different historical questions`.

Pagination strengthens this model because it supplied a stable retrieval coordinate into a mobile source packet.

## 7. Current guardrails

Do not claim:

- Leibniz read the Bremen 1697 edition in 1694;
- the 1694 pagination proves a printer's proof;
- the page numbers necessarily match the final 1697 pagination exactly;
- Leibniz possessed the entire written Hessian Chronicle when these notes were made.

Safe claims:

- Leibniz's own early notes contain page locators to `W. Hassicae Chron.`;
- a written Hessian Chronicle existed before the 1697 publication;
- an excerpt reservoir was separately available and routed through `Geographica`;
- the exact material carrier of the pagination remains unresolved.

## 9. Working proposition

> By the early 1690s Leibniz was working from a pre-publication Winkelmann/Hessian source environment in which excerpted material already carried stable page locators. These locators were then used inside mobile problem files and cross-references before the 1697 printed edition stabilized the work bibliographically. The archive therefore preserves not simply pre-publication reading, but a retrieval infrastructure operating across manuscript, excerpt and classificatory states.
