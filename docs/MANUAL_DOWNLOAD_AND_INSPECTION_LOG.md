# Manual download and inspection log

This is the single operational queue for sources that are faster or more reliable for the user to open, download, or inspect manually than for automated page routing to continue probing. Add every such request here when it is issued. Do not leave manual requests only in chat or scattered analytical notes.

Statuses:

- `pending_user_batch` — save for the user's next batch manual pass;
- `partial_manual_needed` — text/metadata are controlled, but one bounded image/page check still matters;
- `resolved_no_manual_needed` — automated/OCR/other primary control later made the manual step unnecessary;
- `done_user` — user has supplied or confirmed the requested page/image.
