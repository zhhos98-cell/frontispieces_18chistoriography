# Winckelmann 1664: genealogy of the `original Staden blocks` claim

Date: 2026-08-28  
Status: BIBLIOGRAPHIC-GENEALOGY CHECKPOINT — THE MODERN `32 ORIGINAL 1557 BLOCKS` FORMULA SHOULD NOT BE TREATED AS A TRANSPARENT RESTATEMENT OF WINCKELMANN 1664. A TRACEABLE HISTORY OF INCREASING BIBLIOGRAPHIC CERTAINTY IS NOW VISIBLE; THE KEY 1925/1927 WEGNER WORDING REMAINS THE MAIN UNRESOLVED HINGE.

## Result

The repository's earlier guardrail can now be historicized rather than stated only as a conflict between JCB and Obermeier.

Current evidence supports the following layered sequence:

`1664 WINCKELMANN: recovered ~34 blocks + Staden attribution ("sonder Zweifel")`

→ `1870 QUARITCH: physical/book description mentions portrait + woodcuts, but no original-block identity claim`

→ `1925 / 1927 WEGNER: first modern scholarly facsimile/commentary; exact p.19 wording still unresolved and now the priority hinge`

→ `1930s BIBLIOGRAPHIC HARDENING: first-edition-image language becomes explicit; Sabin/Vail eventually says original woodcuts and then same blocks`

→ `MODERN JCB/OPEN LIBRARY: numericalized formula — 32 text illustrations from original Marburg 1557 woodblocks + two non-Staden provenance exceptions + two reported name-elimination states`

→ `OBERMEIER: reopens the physical question and narrows the secure claim to only some / a portion of surviving original block stock`.

Therefore the modern JCB formula is not presently an evidentiary endpoint. It is itself an object of bibliographic history.

The safe repository status remains:

`AT LEAST SOME ORIGINAL 1557 MATRIX REUSE IN 1664 = STRONGLY SUPPORTED`

while

`32 × SAME_MATRIX_AS_1557 = NOT YET VERIFIED BY REPOSITORY-LEVEL PAIRWISE PHYSICAL CONCORDANCE`.

## 1. Starting point: Winckelmann's own 1664 p.136 claim is attribution, not concordance

The primary wording already recovered in this repository is crucial because it defines what later bibliography could harden.

Immediately before introducing the rediscovered block stock, Winckelmann says that he had not been able to ascertain whether Staden's description together with its wood figures had ever been printed:

`Ob aber solche Beschreibung mit den Holzfiguren in Druck seye befordert worden / hab in keine Erfahrung bringen können`.

He then reports that roughly thirty-four woodcuts had recently been found at Kassel and says Hans Staden had `sonder Zweifel` caused them to be designed and cut.

Thus the 1664 structure is:

`RECOVERED OLD BLOCK STOCK`
+
`ATTRIBUTION TO STADEN AS "SONDER ZWEIFEL"`

not:

`KNOWN 1557 EXEMPLAR`
→ `IMPRESSION-BY-IMPRESSION COMPARISON`
→ `34 SAME MATRICES VERIFIED`.

See:

`docs/WINCKELMANN_1664_P136_PROVENANCE_ATTRIBUTION_AND_P168_P179_SCENE_CONCORDANCE_2026-08-28.md`.

## 2. 1870 Quaritch supplies a useful pre-Wegner neutral control

Bernard Quaritch's monthly catalogue no. 260, *Bibliotheca Typographica, Xylographica, et Palaeographica*, was issued in July 1870.

Its item 596 is Winckelmann's 1664 *Der Americanischen Neuen Welt Beschreibung*. The entry explicitly notices its visual apparatus:

- `large folded portrait`;
- `several woodcuts in the text`.

It does **not** identify those woodcuts as the original Staden matrices, as impressions from the 1557 blocks, or as `same blocks`.

Source controls:

- Quaritch catalogue no.260 digitized text: https://www.scribd.com/document/614250765/Quaritch-Catalogue-No-260
- Arlima Quaritch catalogue chronology: no.260, 1870-07-01: https://arlima.net/librairies/quaritch/index.html

Evidence status:

`1870 PROFESSIONAL XYLOGRAPHIC/RARE-BOOK CATALOGUE = NEUTRAL VISUAL DESCRIPTION`.

This is negative evidence only. It does not prove that physical same-matrix identity was unknown or false. It does show that the strong later formula was not necessary to describe or market this copy even in a catalogue explicitly concerned with xylography.

This matters because it creates a pre-1920s control against reading the later language as timeless bibliographic consensus.

## 4. Wegner 1925 / 1927 is now the critical hinge

Richard N. Wegner produced the first modern scholarly facsimile edition with commentary:

1925:

*Warhaftige historia und beschreibung eyner landtschafft ... Faksimile-Wiedergabe nach der Erstausgabe "Marpurg uff fastnacht 1557" mit einer Begleitschrift von Richard N. Wegner.* Frankfurt a.M.: Wüsten & Co.

The first edition's commentary is catalogued as 27 pages.

1927:

second expanded edition, with a 52-page `Begleitschrift`, six illustrations and one map.

Modern JCB/Open Library cites:

`Wegner, R. N. Begleitschrift, 19`.

Controls:

- Open Library 1925 edition, OL6697429M / LCCN 27000720: https://openlibrary.org/books/OL6697429M/
- 1927 second expanded edition catalogue description: https://www.abebooks.com/Warhaftige-Historia-Beschreibung-eyner-Landtschafft-wilden/32429419470/bd
- Obermeier's reception history identifies Wegner 1925/1927 as the first well-commented scholarly facsimile tradition.

Directly recover Wegner p.19 and classify the exact proposition:

Until p.19 is directly inspected, **do not write that Wegner originated the modern same-matrix claim**.

## 5. 1930s: the claim visibly hardens

### 1930 Brazilian scholarly/editorial language

A 1930 Brazilian Academy Staden publication surfaced in web indexing with language describing Winckelmann's reuse in terms of the engravings of the first edition (`gravuras da 1ª edição`).

This supports composition/edition-lineage recognition by 1930, but `first-edition engravings` remains semantically weaker than `same physical blocks` and should not be normalized into matrix identity.

### 1932–1933 Sabin, vol. XXIII

The relevant Staden entry occurs in *A Dictionary of Books Relating to America*, vol. XXIII, a late continuation published 1932–1933, not in Joseph Sabin's nineteenth-century lifetime volumes.

The entry states that Winckelmann's 1664 paraphrase includes:

`thirty-four of the original woodcuts of the Marpurg editions, the blocks for which he found at Cassel`.

Digitized vol. XXIII:

https://upload.wikimedia.org/wikipedia/commons/d/d4/A_dictionary_of_books_relating_to_America%2C_from_its_discovery_to_the_present_time_-_by_Joseph_Sabin_%28IA_dictionaryofbook23sabi%29.pdf

Important provenance guardrail:

The later volumes of Sabin were completed after Sabin's death; bibliographic authority for the 1930s wording should therefore be cited as the late Sabin continuation / Vail-era project rather than casually attributed to `Sabin` as a nineteenth-century witness.

### 1936 Sabin/Vail-era Winckelmann entry

The later Winckelmann entry goes further and describes the 1664 woodcuts as printed from the `same blocks` used for the first Staden edition.

This is a material-matrix proposition, not merely iconographic derivation.

Chronological consequence:

`same blocks` is demonstrably present in the 1930s bibliographic tradition.

It cannot currently be back-projected automatically into Wegner 1925 without inspecting Wegner's text.

## 6. 1942 reception preserves an attribution distinction surprisingly close to the primary evidence

A 1942 Brazilian genealogy journal discussing Staden reports that about thirty woodcuts were recovered with the portrait and says that Winckelmann `classificou de originais` — classified them as originals.

Source surfaced in indexed scan:

https://es.scribd.com/doc/104003860/Genealogia-Revista-1-1942

This is secondary reception, not independent physical control. But its formulation is historiographically useful because it preserves an epistemic distinction lost in later catalogue shorthand:

`WINCKELMANN CLASSIFIED / ATTRIBUTED THEM AS ORIGINALS`

rather than

`MODERN OBSERVER VERIFIED EVERY MATRIX AS ORIGINAL`.

That is strikingly compatible with the primary p.136 `sonder Zweifel` attribution structure.

## 7. JCB's modern note should itself be decomposed

The current JCB-derived Open Library record states:

- 32 text illustrations in the Staden narrative were printed from the original Marburg 1557 woodblocks rediscovered by Winckelmann;
- p.168 and p.179 lack names present on the originals;
- p.18 and p.74 are definitely not from Staden's original work;
- therefore Winckelmann's p.136 all-34 origin claim is materially overinclusive.

Open Library record:

https://openlibrary.org/books/OL33153163M/Der_americanischen_Neuen_Welt_Beschreibung

JCB individual p.142 record independently says:

`These illustrations were reprinted from the original woodcuts used in Hans Staden ... Marburg, 1557.`

https://jcb.lunaimaging.com/luna/servlet/detail/JCB~1~1~4830~7600003

The edition note cites:

1. `JCB Lib. cat., pre-1675, 3:122-123`;
2. Moraes, revised/enlarged *Bibliographia Brasiliana*, pp.944–946;
3. Wegner, `Begleitschrift`, p.19;
4. Fouquet, `Die Ausgaben der Wahrhaftigen Historia 1557–1964`, p.32;
5. Alden, *European Americana*, 664/195.

### Critical bibliographic correction

The citation label `JCB Lib. cat., pre-1675` can sound like an early historical witness. The relevant multi-volume John Carter Brown catalogue volume 3, covering 1659–1674, is a twentieth-century publication (1931). It therefore does not by date itself provide pre-modern physical provenance for the claim.

The phrase `pre-1675` describes the chronological scope of the books catalogued, not the date of the catalogue assertion.

This distinction must remain explicit in repository prose.

## 8. Obermeier reopens what the twentieth-century bibliography had closed

Franz Obermeier's 2014 comparative table gives the 1664 illustration history as:

`Ill: Princeps (teilweise) ... wohl nur ein Teil der originalen Druckstöcke erhalten, keine korrekte inhaltliche Zuordnung, illustrativ eingesetzt.`

Source:

Franz Obermeier, `Deutsche Reiseliteratur über Südamerika im 16. Jahrhundert`, *kunsttexte.de* 3/2014, indexed PDF: https://edoc.hu-berlin.de/server/api/core/bitstreams/6545ea0e-5280-4343-90b5-24771ddf9aa8/content

This is narrower than the modern JCB bulk formula in two separate ways:

1. only part of the original block stock is treated as surviving;
2. images are redeployed without correct original textual placement.

The repository should therefore resist a false choice between `JCB is right` and `Obermeier is right` at the level of authority alone.

Instead:

- JCB supplies a strong catalogue-level matrix attribution and useful item/state leads;
- Obermeier supplies a narrower modern reconstruction and warns against numerical totalization;
- direct item-level visual comparison decides matrix identity.

## 9. Revised evidence model

The `original block` claim now has its own stratigraphy:

### Layer A — 1664 authorial material-provenance narrative

`~34 blocks rediscovered at Kassel`
+
`Staden attribution = sonder Zweifel`
+
`rescue from destruction / renewed use`.

### Layer B — nineteenth-century book-market description

Visual apparatus recognized, but surfaced 1870 professional xylographic catalogue does not make a same-block claim.

### Layer C — 1920s scholarly facsimile reconstruction

Wegner becomes a modern scholarly mediation point; exact p.19 proposition still open.

### Layer D — 1930s bibliographic hardening

`original woodcuts`
→ `blocks found at Cassel`
→ `same blocks as first edition`.

### Layer E — later numerical/catalogue stabilization

`32 original-block impressions`
+
`2 non-Staden exceptions`
+
`2 name-elimination state anomalies`.

### Layer F — modern matrix reopening

`some / portion original blocks`
+
`recontextualized use`
+
`pairwise matrix proof still required`.

This means that `same_matrix_as` is not merely a technical metadata field. Its certainty has a historiography.

## 11. Repository-level payoff

The Winckelmann/Staden case now joins a central project theme from a new direction:

`OBJECT / MATRIX HISTORY`
≠ `BIBLIOGRAPHIC CLAIM HISTORY`.

A catalogue statement about physical identity can itself acquire stability through citation, compression and repetition. That stability is historically meaningful, but it is not identical to physical proof.

The case therefore supplies a second-order method for the whole frontispieces repository:

> whenever a later catalogue says `same plate`, `same block`, `original plate`, or `reprinted from the original`, trace the genealogy of that assertion separately from the genealogy of the object.

Working formula:

`MATRIX PROVENANCE`
≠ `PROVENANCE-CLAIM PROVENANCE`.

Both must be reconstructed.
