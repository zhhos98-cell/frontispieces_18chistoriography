# Round closure: Winkelmann source routing, distributed revision, and print stabilization, c.1690–1711

Date: 2026-08-28
Status: ROUND CLOSED FOR CURRENT SWEEP — ARCHIVAL ROUTING, PREPRINT SOURCE STATE, COURT REVISION, CONTINUED SOURCE SUPPLY, AND PRINTED EVIDENTIARY SELF-PRESENTATION NOW SEPARATED; ITEM-LEVEL KASSEL CENSORIAL CONTENT AND 1697 PRELIMINARY LEAVES REMAIN OPEN

## 1. Current result in one sentence

The Winkelmann case now supports a multi-stage production model in which historical knowledge moved through a distributed infrastructure:

`whole written source / authorial manuscript`
→ `excerpt reservoir`
→ `problem-file routing`
↔ `court/archive source supply`
↔ `joint princely review / censorship`
↔ `authorial revision workspace`
→ `temporary print stabilization`
→ `public evidentiary self-presentation`.

This is not a single influence chain and not a linear passage from manuscript to print. It is a versioned, distributed, jurisdictionally negotiated historical-production regime.

---

## 2. Leibniz-side routing is now controlled at several levels

### A. `Insignia` is a real working-file infrastructure

The official Leibniz-Katalog returns a large normalized `Insignia` corpus, including excerpts, correspondence, seals, diplomas, arms, coins, images, research queues, and cross-file references.

The decisive record remains ID 7139, June 1690:

`Winkelman ex excerpt. Heßischer Chronick. liegen bey Geograf.`

This is a direct operational cross-reference from an `Insignia` note to a `Geographica` retrieval location.

### B. Reverse sweeps show jurisdiction by question

`Insignia`, `Geographica`, and `Genealogica` do not behave as media-exclusive boxes.

The same classes of evidence can move among them depending on the historical problem being asked.

Working principle:

`same witness`
→ different historical question
→ different filing jurisdiction.

### C. Leibniz's own routing language is spatial and operational

Controlled phrases include forms such as:

- `liegen bey Geogr.`;
- `gehören ... zu inquirendis`;
- `ist zu inquirendis gelegt`;
- `so ich gelegt bey Orig. Est.`;
- formal taxonomic `huc`.

This supports the interpretation that later library classifications compress relations already enacted in the working archive.

## 3. Reimmann is no longer the main explanation for Genealogica/Heraldica entering Leibniz's taxonomy

The c.1693 N.78–81 sequence already contains genealogy and insignia/arms before Reimmann 1694 can serve as a necessary trigger.

Therefore the previous `Reimmann 1694 chronological influence window` is downgraded.

The remaining Reimmann question is narrower:

- possible effect on later compression, terminology, or genealogy-historicization;
- direct pre-1701 reception remains unproved.

A stronger direct lexical/reception comparator is Spener, whom Leibniz demonstrably read, annotated, and excerpted, including heraldic material.

## 4. Winkelmann source architecture: at least two source reservoirs

### A. `De dynastiis`

A pair of June 1690 Leibniz excerpts, now Bl.124–125, were originally written on one sheet and later cut apart.

This is a physically reconstructed source-generated extraction unit.

### B. Hessian Chronicle / Geographica reservoir

Independent problem files point to Winkelmann/Hessian excerpts stored with `Geographica`.

The critical edition explicitly notes that the exact excerpt referred to from the 1690 `Insignia` cross-reference has not been recovered.

Therefore:

`GEOGRAPHICA WINKELMANN RESERVOIR = OPERATIONALLY CONTROLLED`

but

`SURVIVING PHYSICAL PACKET = NOT RECOVERED`.

This archival non-recovery is itself part of the source history and must not be silently replaced by a modern reconstruction.

## 5. Pre-1697 source state is directly controlled

Around 1691 Leibniz explicitly distinguishes the excerpts/material he already had from Winkelmann's:

`geschriebene heßische Chronick selbst`.

He wished to read the written Chronicle itself if permission could be obtained, especially if printing would be delayed.

Winkelmann's own manuscript wording in the same working environment refers to:

`meiner lezten und teutschen heßischen Chronik`.

Thus the work existed in a written/pre-print state before 1697.

Safe source-state sequence:

`written Chronicle exists`
→ `partial excerpt access to Leibniz`
→ `whole manuscript access not established`
→ `1697 print state`.

## 6. Pagination: modern source alignment and Leibniz's own page references must remain separate

Two different phenomena are now controlled.

### A. Modern catalogue alignment

Some Leibniz-Katalog `Exzerpierte Stelle` fields identify 1694 working notes against specific pages of the later 1697 print.

Those catalogue page locators cannot by themselves prove that Leibniz's pre-print source had identical pagination.

### B. Leibniz autograph pagination

ID 11623 is different: Leibniz's own note begins:

`Ex W. Hassicae Chron. p. 6.`

and continues with further page references including p.41, 56, 59, 96.

Therefore the source/excerpt state used by Leibniz itself possessed stable pagination or stable page-reference markers.

The later 1697 print preserves enough textual/page continuity for editors to align many of these references.

Current safe interpretation:

`PREPRINT PAGINATED SOURCE STATE = CONTROLLED`

while

`EXACT SOURCE FORM = unresolved`.

It may have been:

- a paginated whole manuscript;
- a paginated manuscript copy;
- a paginated excerpt packet preserving source page numbers;
- a printer/pre-publication copy.

Do not collapse these possibilities.

## 7. Authorial manuscript is a revision workspace, not a clean fair copy

Oldenburg `Cim I 204` supplies the author-side material control.

The manuscript is described as an authentic authorial codex with:

- numerous insertions and additions;
- two differently corrected states of Book IV;
- extensive authorial revision;
- fols.543r–552v containing `Extracten aus den Hochfürstl. Schreiben die hessische Chronic betreffend`.

The same manuscript complex originally included a separate:

`Relation wegen Verlaufs und verhinderter Publication der Hessischen Chronik de Anno 1648 bis 1696`,

later transferred to Darmstadt and now not recovered in the current sweep.

This authorial codex should therefore be treated as:

`REVISION WORKSPACE + PRODUCTION DOSSIER`.

## 8. Court review was constitutive, not a late pre-publication event

The production history reaches back to the first major manuscript-delivery phase.

By 1654–57 the first four planned parts had been submitted to the two princely commissioning sides, after which a joint/bilateral commission reviewed the work.

Later scholarship reconstructs recurrent revision and censorship involving both Hessian princely/government sides.

The disputes concern at least three distinct jurisdictions:

1. **confessional acceptability** — Reformed/Lutheran tensions;
2. **dynastic/political representation** — what could be said about ruling houses, territories, and historical claims;
3. **epistemic/historical standards** — working method, historical credibility, and missing/inadequate source references.

Therefore `Zensur` here must not be reduced to political deletion.

It also regulates what kind of historical claim counts as sufficiently documented and publishable.

Working label:

`DISTRIBUTED REVISION REGIME`.

## 10. Source supply continues into the publication window

Darmstadt `HStAD D 4, 214/4` preserves a late supply-side control.

Around 1697–98 a request was made to send the `Lebenslauf` of Landgrave Ernst Ludwig to historiographer Winkelmann in Bremen `zur Abfassung einer Chronik`.

This matters because it shows that the publication-state text was still receiving official biographical material close to or after the 1697 printing window.

Therefore the production model is not:

`closed manuscript`
→ `mechanical print`.

It is closer to:

`long-running versioned compilation`
+
`continued source inflow`
+
`review/revision`
→ `temporary print stabilization`.

## 11. 1697 print creates a public evidentiary persona while admitting incompletion

The 1697 title page states that the work was composed:

`Aus den glaubwürdigsten Documenten und Scribenten in Sechs Theilen verfasset`

but immediately adds:

`Aber vors erste werden Fünf Theile publiciret.`

This establishes directly:

`six-part project identity`
≠
`five-part first publication state`.

The title also makes a public epistemic claim:

`glaubwürdigsten Documenten und Scribenten`.

This is especially important because the archival production history independently shows disputes about method, credibility, and source references.

Safe relation:

`archival credibility negotiation`
↔
`printed public claim to credible documents/writers`.

Do not yet claim the title formula is a direct textual response to a particular censorial memorandum.

The 1711 reprint retains the six-part/documentary-credibility formulation but drops the explicit 1697 sentence announcing that only five parts are being published for now; the substantive sixth part still does not appear until 1754.

Working labels:

`PRINTED EVIDENTIARY SELF-PRESENTATION`

`PROJECT IDENTITY ≠ PUBLICATION STATE`

`TEMPORARY TEXTUAL STABILIZATION`.

## 12. Wider analytical payoff for the frontispiece repository

The Winkelmann case now gives a concrete production-history analogue to the repository's material rule:

`programme identity ≠ composition identity ≠ plate identity ≠ impression/copy identity`.

For historical texts:

`project identity`
≠ `whole written source`
≠ `excerpt reservoir`
≠ `problem note`
≠ `reviewed/revised state`
≠ `publication state`
≠ `later completion state`.

The larger conceptual sequence is now:

`distributed archival evidence`
→ `problem-oriented routing`
→ `taxonomic compression`
→ `institutional/review jurisdiction`
→ `temporary textual stabilization`
→ `public visual/textual coordination`.

This supports a stronger article-level proposition:

> Historical coherence was often produced by coordinating materially distributed, differently authorized, and repeatedly revised witnesses. Stable classifications, printed titles, and visual programmes should be treated as outcomes of that coordination rather than as transparent reflections of already-stable disciplines or texts.

No direct Winkelmann → Weigel/Köhler causal edge has been established.

## 13. Explicitly closed / downgraded questions

### Closed for current purposes

- Reimmann 1694 is not required to explain the first appearance of genealogy/insignia in Leibniz's c.1693 taxonomic drafts.
- The 1694/1697 chronology does not imply impossible pre-reading of a future printed book; a written/pre-print Hessian Chronicle is directly controlled.
- Leibniz's page references are not merely modern editorial artefacts; at least ID 11623 contains autograph pagination references.
- The Geographica-side Winkelmann excerpt reservoir was operationally real even though the exact physical packet is not currently recovered.

### Downgraded

- `Reimmann 1694 → Leibniz classification` as a leading causal hypothesis.
- `closed printer manuscript → 1697 print` as the default source-state model.
- `censorship = political deletion only`.
