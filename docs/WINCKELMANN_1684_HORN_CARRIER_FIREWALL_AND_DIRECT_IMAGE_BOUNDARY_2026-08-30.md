`DIRECT OBJECT ACCESS AS AN EPISTEMIC WARRANT = CONTROLLED`.

## 4. Reported heraldic discrepancy remains high-value but mechanism-open

Gitte Kjær's object-history study reports that Winckelmann's representation shows Oldenburg heraldic bars/arms absent from the surviving object and that this feature propagated through later representation/cataloguing traditions.

Current status:

`SURROGATE ↔ PRESENT OBJECT HERALDIC DISCREPANCY = SCHOLARLY OBJECT-COMPARISON CONTROLLED`

`CAUSE = OPEN`.

Candidate mechanisms remain:

- interpretive supplementation by Winckelmann;

The direct scan is needed to establish the exact printed form, not to reopen the broader historical chain.

## 5. 1696 Jacobaeus control

*Museum Regium* (Copenhagen, 1696) contains the Oldenburg Horn as **Tab. XVI**; the text identifies `CORNU OLDENBURGICUM` and uses the object's heraldic features in historical/chronological reasoning.

Kjær reports the 1696 copperplate as apparently based on the visual model published by Winckelmann in 1684.

Safe relation:

`1696 TAB XVI PRESENCE = DIRECT BIBLIOGRAPHIC/TEXTUAL CONTROL`

`DERIVED_FROM 1684 = STRONG SCHOLARLY REPORTED RELATION, DIRECT IMAGE COMPARISON PENDING`.

Because Jacobaeus also had access to the royal collection after the Horn's transfer to Copenhagen, image similarity alone must not be used to infer textual or interpretive dependence.

## 6. 1807–08 long-range reuse remains controlled

The existing correspondence/research chain records that Göttingen librarian Beneke supplied `den Winkelmann` in response to a request for a good Horn image because it contained `die beste Abbildung`; modern scholarship identifies Winckelmann's image as the model for the 1808 *Des Knaben Wunderhorn* threshold/title copper.

This relation is not endangered by the digital-carrier warning because the nineteenth-century actors were consulting historical exemplars, not the 1912 Oldenburg digital replacement.
