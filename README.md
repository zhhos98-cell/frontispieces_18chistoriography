# Frontispieces and Eighteenth-Century Historiography

Status: **CLOSED — 2026-08-30**.

This repository is a frozen provenance-first corpus on engraved frontispieces, plate reuse, copy variation, and the visual/material infrastructures of historical evidence. Public-web discovery and generic expansion are closed. The canonical research and colour-question queues are frozen; there are no active blocking user actions.

## Start here

1. `FINAL_CLOSURE_2026-08-30.md` — authoritative narrative closure.
2. `CLOSURE_STATE_2026-08-30.json` — machine-readable repository state.
3. `CURRENT_HANDOFF.md` — compact restart/handoff record.
4. `docs/USER_ACTION_LOG.md` — completed bounded user-assisted checks.
5. `docs/EVIDENCE_POLICY.md` — evidence-status and promotion rules.

Older `OPEN`, `Priority`, `next round`, `CURRENT*`, sweep, and checkpoint language is research provenance rather than a live instruction when it conflicts with the closure files above.

## Repository map

- `data/` — canonical structured research data and frozen question queues.
- `schema/` — data schemas.
- `docs/` — evidence policy, controlled analyses, source closures, and object-level audit records.
- `archive/` — superseded or pre-closure material retained for provenance. The full pre-closure README is preserved as `archive/README_PRE_CLOSURE_2026-08-30.md`.

## Reopen rule

Reopen only a bounded branch when a new direct image/object, a known archival/manuscript source, a new primary source that can change a retained claim, or a load-bearing writing/citation gap creates a concrete test. Do not restart generic web accumulation or restore old priority queues for completionism.

Core evidentiary distinctions remain binding:

`programme identity ≠ design identity ≠ matrix identity ≠ impression/copy identity`

`unresolved assertion ≠ active research obligation`
